Support

Questions, bugs, requests.

Which Unity versions are supported?

Built and tested in Unity 6 (6000.x). The source assets target Unity 2022.3 LTS and newer; the exact tested version is listed on the store page.

Which render pipelines are supported?

URP works out of the box and is what the shipped materials use. For HDRP, run the materials through the Render Pipeline Converter and use the included Mask Map; for the Built-in pipeline, switch the materials to the Standard shader and relink the Metallic-Smoothness, Normal and Occlusion maps. Both routes are documented in the user guide — for HDRP, the FBX models are the safer path.

Do the GLB files need anything extra?

Yes. Unity has no built-in glTF importer, so the GLB models and prefabs need the free open-source UnityGLTF package from the Khronos Group. Install it once from Window > Package Manager > + > Add package from git URL using https://github.com/KhronosGroup/UnityGLTF.git (Git must be installed), then reimport the glb folder. Offline steps and the required build settings are in the user guide. The FBX prefabs need nothing extra.

What textures and formats are included?

One PBR set per prop — 22 in total: 512×512 for the two wooden cups, 1024×1024 for most props and 2048×2048 for the two large tables. Maps are Base Color, Normal, Occlusion, Metallic-Smoothness, Mask Map and ORM. Models come as FBX and GLB.

Licence and refunds?

Standard Unity Asset Store EULA: commercial use is allowed, reselling the source assets is not. Refunds follow Unity's policy — if something is broken on my side, write to me first and I'll fix it fast.
